# اعمال بسته MW-Site-Release-2026-11-04

بسته شامل ۲۶ پچ و نسخه نهایی ۴۰۶ فایل است. تغییرات با نسخه موجود مقایسه و ادغام شدند؛ بخش‌های از قبل اعمال‌شده دوباره اعمال نشدند. فایل‌های معرفی‌شده برای حذف (`composer.phar` و `repro_save.php`) در این checkout وجود نداشتند.

## دامنه تغییرات

- خرید مادهای پولی و تحویل نتیجه پرداخت به لانچر، باشگاه و پروفایل VIP، گزارش مصرف امتیاز، برگشت پاداش سفارش مرجوعی، قهرمانان و پاداش فروشندگان.
- لندینگ‌ساز و لندینگ محصول سفارشی، تنظیمات جشنواره و یکپارچه‌سازی‌ها، بهبود گالری، استوری‌ها، صفحه اصلی و فوتر.
- ۱۴ فایل مایگریشن جدید نسبت به checkout فعلی؛ اجرای واقعی آن‌ها به وضعیت دیتابیس مقصد بستگی دارد.

اصلاحات قبلی پروژه در ثبت استثنای اصلی ذخیره تنظیمات (`executeOrFail`)، زنجیره استثناهای JSON، تأیید حذف پنل و محدودیت دسترسی لندینگ حفظ شدند. تفاوت دو فایل config لندینگ با بسته فقط فاصله انتهای خطوط بود؛ محتوای فعلی حفظ شد.

دو تست قدیمی با رفتار جدید بسته هماهنگ شدند: اصلاح UTF-8 ناسالم هنگام ذخیره و تکمیل فیلدهای غایب سند لندینگ از پیش‌فرض‌ها. اعتبارسنجی لینک و ساختار نامعتبر همچنان بررسی می‌شود.

## استقرار

دیتابیس فعلی، سیدرها و سرویس‌های در حال اجرا در این کار تغییر داده نشدند. پس از پشتیبان‌گیری، روی محیط مقصد این مراحل لازم است:

```sh
composer install --no-dev --optimize-autoloader
npm ci
npm run build
php artisan migrate --force
php artisan db:seed --class="Database\Seeders\Identity\PermissionSeeder" --force
php artisan scribe:generate
php artisan optimize:clear
php artisan optimize
php artisan queue:restart
```

طبق راهنمای بسته، اجرای سیدر عمومی و DemoContentSeeder روی سایت اصلی می‌تواند چیدمان یا داده‌ها را تغییر دهد؛ فقط سیدر دسترسی بالا لازم است. کش‌های برچسب‌دار به Redis نیاز دارند. برای رفتار جدید خرید ماد، نسخه لانچر مورد اشاره بسته 1.21.111 است.
