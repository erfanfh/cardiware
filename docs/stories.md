# مدیریت استوری‌های صفحهٔ اصلی

## استفاده در پنل

- از منوی «استوری‌ها» وارد فهرست شوید؛ مسیر: `/admin/stories`.
- هر آیتم شامل عنوان، زیرعنوان و توضیحات اختیاری، تصویر اصلی، کاور اختیاری، لینک و متن دکمهٔ اختیاری است.
- تصاویر از کتابخانهٔ رسانه انتخاب یا بارگذاری می‌شوند و باید عمومی و آماده باشند. تصویر عمودی ۹:۱۶ برای محتوای اصلی مناسب است. تصویر اصلی بدون برش نمایش داده می‌شود؛ کاور به صورت دایره‌ای برش می‌خورد.
- بدون کاور، تصویر اصلی جایگزین آن می‌شود. بدون لینک، دکمهٔ جزئیات نمایش داده نمی‌شود.
- مدت نمایش هر آیتم بین ۳ تا ۶۰ ثانیه است. ترتیب کمتر مقدم است؛ در ترتیب یکسان، شناسهٔ کمتر مقدم است.
- آیتم جدید به صورت پیش‌فرض غیرفعال است. زمان شروع خالی یعنی نمایش بلافاصله پس از فعال‌سازی؛ پایان خالی یعنی بدون انقضا. زمان‌ها بر اساس منطقهٔ زمانی برنامه (`Asia/Tehran`) هستند و در ورودی تاریخ میلادی ثبت می‌شوند؛ جدول، تاریخ‌ها را شمسی نمایش می‌دهد.
- فهرست، جستجو بر اساس شناسه و عنوان، فیلتر فعال‌سازی، مرتب‌سازی ستون‌ها، صفحه‌بندی و فعال‌سازی، غیرفعال‌سازی و حذف گروهی دارد.
- برای نمایش، عنصر «استوری» باید در چیدمان صفحهٔ اصلی نیز فعال باشد. لینک تنظیمات این عنصر به فهرست مدیریت استوری‌ها متصل است.

## دسترسی و رفتار عمومی

مجوزهای مستقل `story.list`، `story.create`، `story.edit` و `story.delete` برای نقش‌ها وجود دارد. عملیات گروهی نیز مجوز متناسب با عملیات را بررسی می‌کند. تغییرات در تاریخچهٔ عمومی سامانه ثبت می‌شوند.

فرانت فقط آیتم‌های فعال در بازهٔ انتشار را با تصویر عمومی و آماده نمایش می‌دهد. آیتم منقضی دقیقاً از زمان پایان حذف می‌شود. کش با تغییر استوری یا رسانه باطل می‌شود و تا نزدیک‌ترین شروع یا پایان زمان‌بندی‌شده اعتبار دارد. در نبود آیتم قابل نمایش، کل بخش استوری مخفی است؛ دادهٔ نمونهٔ ثابت نمایش داده نمی‌شود.

نمایشگر از حرکت خودکار، قبلی/بعدی، توقف/ادامه، نگه‌داشتن لمس/ماوس، کلیدهای جهت مطابق RTL و Escape پشتیبانی می‌کند. فوکوس داخل پنجره نگه داشته می‌شود و هنگام بستن به دکمهٔ آغازین برمی‌گردد.

## نصب و بررسی

پس از دریافت کد:

```sh
php artisan migrate
npm run build
```

Migration جدول و مجوزها را ایجاد می‌کند. Seeder مجوزها نیز با این گروه هماهنگ شده است. استوری‌های نمونهٔ استاتیک به دادهٔ واقعی تبدیل نمی‌شوند؛ محتوا را از پنل اضافه کنید.

آزمون‌های مرتبط:

```sh
php vendor/phpunit/phpunit/phpunit --bootstrap vendor/autoload.php tests/Feature/Story/StoryManagementTest.php
node --test tests/Frontend/story-viewer.test.mjs
```
