# اعمال بستهٔ ۲۰ پچی — ۲۰۲۶/۱۱/۰۱

بستهٔ `_deployment-package.zip` روی نسخهٔ `8bbe68b0` پروژه، به‌ترتیب پچ‌های ۱ تا ۲۰ و بدون ایجاد کامیت اعمال شد. تغییرات شامل لندینگ‌های PGL، باشگاه و XP، همکاری در فروش، گالری کاربران و بازطراحی صفحات عمومی است. مقدار پیش‌فرض کمیسیون همکاران جدید ۱۱٪ است؛ نرخ ثبت‌شدهٔ همکاران موجود تغییر نمی‌کند.

## اصلاحات هنگام ادغام

- ارجاع نامعتبر دکمهٔ ذخیره در مدیریت گالری به `admin.form.save-button` و ویژگی صحیح `label` اصلاح شد.
- متن راهنمای کمیسیون در تنظیمات ادمین با پیش‌فرض ۱۱٪ هماهنگ شد.
- فرم‌های حذف جدید گالری، سطوح، مأموریت‌ها و دستاوردها به پنجرهٔ تأیید استاندارد پروژه متصل شدند.
- اعتبارسنجی فیلدهای ضروری لندینگ حفظ شد؛ فقط فیلدهای تازهٔ `enabled`، `hidden` و `pgl_team_id` برای سازگاری با سندهای قدیمی اختیاری‌اند.
- اسکریپت‌های موقت `preview_router.php` و `seed_preview.php` که ورود مستقیم مدیر و حساب آزمایشی می‌ساختند، وارد خروجی نهایی نشدند. نسخهٔ پشتیبان موقت `config/product-landings.php.bak-flags` نیز کنار گذاشته شد.
- فایل‌های `composer.phar` و `repro_save.php` که پچ اول حذف می‌کرد، از ابتدا در این پروژه وجود نداشتند.
- محدودیت دسترسی فعلی لندینگ‌های فارسی به مدیر ارشد حفظ شد.

## استقرار همین نسخه روی سرور

وابستگی‌های Composer و فهرست وابستگی‌های npm تغییر نکرده‌اند. برای ساخت از وابستگی‌های قفل‌شده استفاده کنید:

```sh
npm ci
npm run build
php artisan migrate --force
php artisan db:seed --class='Database\Seeders\Identity\PermissionSeeder' --force
php artisan db:seed --class='Database\Seeders\Layout\PageLayoutSeeder' --force
php artisan optimize:clear
```

سیدر چیدمان، وضعیت فعال بودن، جایگاه و ترتیب عناصر موجود را حفظ می‌کند و عناصر جدید را اضافه می‌کند. برای جایگزینی پروژه‌ها با کارت‌های باشگاه، وضعیت ویجت‌های موجود را در «سایت ← صفحه اصلی (چیدمان)» تنظیم کنید.

ساخت سطوح هفت‌گانه و مأموریت‌ها و دستاوردهای پیشنهادی اختیاری است:

```sh
php artisan db:seed --class='Database\Seeders\Loyalty\LoyaltyLevelSeeder' --force
php artisan db:seed --class='Database\Seeders\Loyalty\LoyaltyGamificationSeeder' --force
```

سیدر گیمیفیکیشن، تنظیمات مهلت انقضا و پاداش زنجیرهٔ ورود را نیز مقداردهی می‌کند؛ پیش از اجرای آن تنظیمات دلخواه مدیر را بررسی کنید. سیدرهای دمو برای استقرار لازم نیستند و هنگام ادغام اجرا نشدند.

در محیط توسعهٔ فعلی، مایگریشن‌ها و سیدرهای مجوز و چیدمان اجرا و کش‌های Laravel پاک شدند. این عملیات روی سرور اصلی انجام نشده است.

## اعتبارسنجی

- ساخت فرانت‌اند با `npm run build` موفق بود؛ Vite فقط هشدار اندازهٔ بعضی خروجی‌ها را نشان داد.
- بررسی نحوی ۱۲۳ فایل PHP واردشده موفق بود. فایل‌های اصلاح‌شدهٔ تنظیمات و تست‌ها نیز جداگانه بررسی شدند.
- ۱۸ تست مرتبط با صفحات جدید، مدیریت گالری و پاداش یک‌باره، تنظیمات لندینگ و ثبت خطای تنظیمات با ۱۳۷ assertion موفق بودند. تست‌ها با `DB_CONNECTION=sqlite` و `DB_DATABASE=:memory:` اجرا شدند.
- `git diff --check` پس از پاک‌سازی فاصله‌های انتهای خطوط دو فایل تنظیمات موفق بود.
- کامپایل نهایی Blade موفق بود و بررسی وضعیت دیتابیس محلی هیچ مایگریشن معوقی نشان نداد.
- هر ۱۰ تست انتساب و برداشت همکاری در فروش نیز در اجرای جامع موفق بود.

### محدودیت نتیجهٔ تست جامع

اجرای جامع با حافظهٔ ۱ گیگابایت پایان یافت: ۹۲۵ تست، ۵۲۷۵ assertion، ۴۴ خطای اجرا، ۱۳ شکست assertion، ۷ تست ردشده و ۲ تست risky. این اجرا هم‌زمان با اصلاحات انجام شد؛ سه مورد مربوط به انتظار قدیمی لاگ، انتظار کد پاسخ دسترسی گالری، و حذف فیلد ضروری لندینگ، پس از اصلاح در اجرای تکمیلی ۱۸ تست بالا موفق شدند. اجرای جامع برای ادعای سبز بودن کل پروژه تکرار نشده است.

موارد باقی‌مانده شامل ناسازگاری داده و mock تست‌های دانلود/بوت‌استرپ لانچر، مسیر قدیمی API، نبود تنظیم پیامک در یک تست قرعه‌کشی، mock منو، دادهٔ چیدمان در تست‌های عمومی، انتظار قدیمی مسیر ورود، قفل ویرایش محصول و چند فرم حذف قدیمی لانچر هستند. کد و تست‌های نامرتبط برای سبز کردن این اجرا تغییر نکردند.

جزئیات این اجرا در `storage/logs/deployment-import-tests.log` و `storage/logs/deployment-import-tests.xml` ثبت شده است.
