# اتصال MW Launcher به Laravel

این شاخه، پیاده‌سازی کامل سمت Laravel برای لانچر ویندوزی است. مدیریت انتشار هر
نسخه فروش، فایل‌های پایه، آپدیت‌ها، مادها، گروه‌های انحصاری ماد، اجرای بازی و
Sider و OPTION FILE از صفحه ویرایش محصول انجام می‌شود. لانچر فقط قرارداد API را
اجرا می‌کند و هیچ URL اصلی دانلودی در Catalog، Library یا Manifest دریافت نمی‌کند.

## قواعد اصلی

- هر `ProductSaleItem` یک محصول مستقل لانچر است؛ بنابراین Half Season و Full
  Season تنظیمات، مالکیت، فایل، آپدیت و ماد مستقل دارند.
- فقط آیتم دارای `launcher_enabled = 1` در Catalog لانچر دیده می‌شود.
- قیمت صفر با endpoint مخصوص claim فعال می‌شود؛ محصول پولی از وب‌سایت خریداری
  و با deep link به لانچر برمی‌گردد.
- هر حساب فقط یک دستگاه فعال و فقط یک فرصت انتقال نهایی با OTP به دستگاه دوم
  دارد. Reset فقط در اختیار پشتیبانی است.
- مجوز آفلاین امضاشده حداکثر ۷ روز اعتبار دارد؛ جزئیات در
  `DEVICE_SECURITY_OFFLINE_FA.md` آمده است.
- همه بسته‌ها 7z هستند. فایل چندپارتی با الگوی `.7z.001`، `.7z.002` و ... نیز
  پشتیبانی می‌شود.
- مسیر پایه نصب را کاربر در لانچر انتخاب می‌کند؛ Laravel فقط
  `install_folder_name` را برمی‌گرداند.
- فایل‌های دانلودی محصول در `<ProductFolder>/_MWDL` نگهداری می‌شوند.
- محتوای استخراج‌شده در ریشه پوشه محصول merge/replace می‌شود.
- اگر OPTION FILE فعال باشد، محتوای پوشه `OPTION FILE` با حفظ ساختار در
  Documents ویندوز merge/replace می‌شود.
- فایل‌های ماد نیز پس از استخراج مستقیماً با ریشه محصول merge/replace می‌شوند.

## نقطه شروع

1. راهنمای استقرار را در `DEPLOYMENT_FA.md` اجرا کنید.
2. متغیرهای `LAUNCHER_*` را در `.env` تنظیم کنید.
3. در پنل مدیریت یک نسخه فروش را برای لانچر کامل کنید.
4. با `API_ENDPOINTS_FA.md` اتصال WPF را آزمایش کنید.

## وضعیت تست

به علت نبود PHP/Composer در محیط آماده‌سازی، تست‌های اجرایی در این محیط اجرا
نشده‌اند. تست route/config داخل پروژه اضافه شده و دستورات دقیق اجرای staging در
راهنمای استقرار آمده است.
