# گزارش پیاده‌سازی

- کاتالوگ مستقل بر پایه ProductSaleItem و تیک انتشار لانچر
- ورود اجباری با یک دستگاه فعال، یک انتقال نهایی با OTP، Device Key و token متصل به دستگاه
- مالکیت مستقل نسخه‌های فروش و claim امن محصول رایگان
- گردش خرید مرورگری و بازگشت deep link به لانچر
- manifest نصب پایه با 7z چندپارتی، SHA-256، `_MWDL` و OPTION FILE
- URL دانلود کوتاه‌عمر، امضاشده، HTTPS و دارای allowlist اختیاری
- نشست دانلود idempotent برای جلوگیری از مصرف چندباره سهمیه در retry
- آپدیت‌های مستقل هر نسخه فروش با چند فایل و OPTION FILE
- مادمنیجر مستقل هر نسخه فروش، تصویر، توضیحات، سازگاری، اولویت و گروه انحصاری
- پنل مدیریت Laravel برای تمام فیلدهای بالا
- API فهرست دستگاه‌ها و لغو دسترسی دستگاه
- تست ثبت routeها و تنظیمات امنیتی
