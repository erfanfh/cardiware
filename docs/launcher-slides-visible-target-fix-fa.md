# اصلاح نمایش همه اسلایدهای فعال لانچر

API دیگر اسلاید فعال را صرفاً به‌دلیل غیرفعال یا حذف‌شدن محصول مقصد حذف نمی‌کند.
در این شرایط اسلاید در لانچر نمایش داده می‌شود، اما مقصد آن به `none` تبدیل می‌شود تا کلیک روی لینک خراب انجام نشود.

در فهرست مدیریت اسلایدر نیز برای مقصد محصول غیرفعال هشدار نمایش داده می‌شود.

پس از انتقال سورس روی سرور:

```bash
php artisan optimize:clear
```
